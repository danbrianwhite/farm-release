# FlashForge Farm

Android 3D printing slicer application with multi-color support, calibration tools, and network printing.

## Downloads

**Latest build**: [Releases → latest](https://github.com/danbrianwhite/farm-release/releases/tag/latest)

## Features

- **Multi-color painting** — brush, bucket, height-range tools with per-filament assignment
- **Slicing engine** — based on OrcaSlicer/libslic3r with full G-code output
- **Calibration suite** — Pressure Advance, Temperature Tower, Flow Rate, Retraction, VFA
- **Network printing** — direct send to LAN printers (Moonraker/Klipper, OctoPrint)
- **Profile management** — import/export, printer/filament/process presets

## Build System

Automated weekly builds from source. See [Actions](https://github.com/danbrianwhite/farm-release/actions) for build history.
